# 安全与隐私说明

更新日期：2026-07-13

## 当前边界

本项目默认用于本机演示与比赛验收。`DEV_PERMIT_ALL=true` 时无需登录，便于本地使用；公开部署前必须切换正式安全模式并配置专业账号。

## 简历隐私

- 简历和能力档案通过 HttpOnly、SameSite=Lax 的匿名会话标识进行本人隔离。
- 不把长期令牌写入浏览器 localStorage。
- 用户可通过删除接口删除自己的简历及其派生匹配、计划和验证记录。
- 演示和提交材料只允许使用脱敏或合成后人工校验的简历。
- 默认 `AI_PROVIDER=local`，岗位证据和抽取文本只发送到本机 Qwen 服务，不发送到云端模型。
- 本地模型不可用时只进入规则或证据不足状态，不自动调用星火。
- 只有部署人员手动设置 `AI_PROVIDER=spark` 时才向讯飞星火发送受证据约束的模型输入；密钥不写入源码、响应或日志。

## 文件安全

- 简历只接受 10MB 以内的文本型 PDF/DOCX，并校验扩展名、MIME 和魔数。
- DOCX 拒绝宏、嵌入对象和缺少正文结构的压缩包。
- CSV/JSON 数据文件限制为 5MB，并使用结构化解析器读取。
- 授权目录只扫描显式配置的目录、最多四层、单文件不超过 1MB，不跟随符号链接。

## 在线来源

- RSS/Atom 连接器默认关闭，只允许显式配置的不含账号信息的 HTTPS 地址。
- 必须填写 `AUTHORIZED` 或 `OPEN` 许可状态和许可说明。
- 禁止自动重定向，响应限制为 2MB，XML 禁止 DOCTYPE 和外部实体。
- 连接失败不会覆盖当前已发布图谱，只保留失败状态供重试。

## 正式模式

公开部署前至少设置：

```text
DEV_PERMIT_ALL=false
SECURE_COOKIE=true
PROFESSIONAL_USERNAME=专业账号
PROFESSIONAL_PASSWORD=高强度密码
```

正式模式下学生简历闭环仍可匿名使用，数据导入、抽取、评测、审核、发布和回滚等专业操作要求账号认证。

## 已自动测试

- 会话 Cookie 创建与复用。
- 不同会话的简历越权拒绝。
- 伪 PDF、伪 DOCX、超大文件、DOCX 宏和嵌入对象拒绝。
- RSS/Atom 非 HTTPS、缺失许可和 XML 外部实体拒绝。
- Prompt Injection 文本不作为系统指令执行。
- 创建人自审、未审核发布、重复版本和重复回滚拒绝。

## 公开部署前仍需完成

- 生产账号与角色名单、强制 HTTPS、真实域名和反向代理配置。
- 登录限流、账号锁定、不可修改的数据库审计表和审计查阅页面；CSRF 与专业角色校验已完成临时正式模式验证。
- 基于正式部署地址的渗透测试、依赖漏洞扫描和日志 PII 抽查。
- MySQL 定期备份、恢复演练和隐私删除留痕。

## P0-6 简历与能力证据边界

- 姓名、电话、邮箱和地址在事实抽取前脱敏；事实锚点、引用片段、日志和前端响应不得包含原始 PII。
- 匿名简历按会话隔离，默认 7 天清理，用户可立即删除；手工修正事实标记为 `USER_CORRECTION`，不伪造原文位置。
- 外部证据只允许 HTTP/HTTPS，需通过可访问性、相关性、代码或文档内容、测试指标检查；检查通过仍需专业角色人工复核。
- 匿名用户不能访问 `/api/admin/verification-submissions/*/reviews`；只有 `VERIFIED` 状态可以更新能力和触发再次诊断。
