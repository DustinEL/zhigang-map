# 产品体验与结构决策

## 参考范围

本次整理对照了公开代码库的成熟交互做法：

- [Vue Vben Admin](https://github.com/vbenjs/vue-vben-admin)：侧栏分组、折叠状态和桌面端工作台布局成熟，采用“信息分层 + 可收起导航”；它偏后台管理，不直接复用其密集表格首屏。
- [create-vue](https://github.com/vuejs/create-vue)：保持 Vue 3、Vite、TypeScript 的轻量工程边界，避免多套入口并存。
- [Ant Design Pro](https://github.com/ant-design/ant-design-pro)：采用概览指标、分区卡片和按需展开的渐进披露方式；其默认企业后台视觉信息量较大，因此本项目将首屏压缩为决策入口和证据摘要。

## 本项目的落地取舍

- 学生端和岗位智能端共用一套应用壳，仍按任务分组，减少页面跳转和重复显示。
- 左侧导航支持收起并记忆状态；移动端切换为底部任务导航。
- 首页不堆叠方案说明，改为“开始诊断 / 浏览方向”两个入口，下面依次呈现数据概览、岗位方向、能力频次、岗位画像和成长闭环。
- 重复说明使用原生 `details/summary` 折叠，默认只展示结论，打开后才展示口径和状态解释。
- 数据卡只使用接口返回的样本数、企业数和岗位数；能力条形图展示样本内排名，不虚构市场百分比或趋势结论。
- 主题视觉统一为蓝白科技风。背景素材放在 `frontend/public/visuals/`，页面不依赖外部图片 CDN。

## 维护边界

`zhigang` 是唯一运行项目；旧副本和早期设计稿已从运行目录移除，不参与启动、构建或发布。新增页面必须复用现有路由、API 和类型，不复制旧版本目录。
